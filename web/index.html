        About Dorksmith

        Dorksmith is a deterministic query compiler for advanced web search. Given a target, an input type and an intent it emits several ranked query variants, explains why each exists and which operators it uses, and warns about operators the search engine no longer supports reliably.

        It is built for defensive exposure reviews, OSINT and SOCMINT research, journalism, troubleshooting and plain-old power searching. There is no login, no account, no AI model and no result scraping: every query is generated locally from a versioned catalog and opened in the search engine by you.

        Usage notice
